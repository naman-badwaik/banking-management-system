# Banking Management System

A console-based Banking Management System developed in C to practice programming fundamentals and build a practical real-world application.

## Features

- Create a new bank account
- Savings and Current account options
- 4-digit PIN-based login
- Check account balance
- Deposit money
- Withdraw money
- Change PIN
- Transaction history
- Date and time recording for transactions
- Account number validation

## Technologies Used

- C Programming
- Structures
- Functions
- Conditional Statements
- Loops
- Arrays
- String Handling
- Date and Time Handling

## Project Purpose

This project was developed to strengthen my understanding of C programming and problem-solving by implementing common banking operations in a console-based application.

## How to Run

1. Download or clone this repository.
2. Open `banking_sys.c` in a C compiler or IDE.
3. Compile the program.
4. Run the executable.
